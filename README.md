## 🎯 What This Is

This is **NOT** about convincing merchants Bitcoin is "freedom money."

This is about showing them the **actual financial benefit** of accepting Bitcoin through Square:

- **0% fees through all of 2026**
- **1% fees starting 2027** (vs 2.6% + $0.15 for credit cards)
- **Their choice:** Hold Bitcoin, auto-convert to USD, or split 50/50

The math: A brewery doing 50/50 could create **$50,328 more business value** over 5 years than credit cards.

## 📊 The Three Strategies

Each analysis shows three options with 5-year projections:

**Option 1: 50/50 Hybrid (Recommended)**
- Half to USD immediately, half stays in Bitcoin
- Certainty (cash) + upside (Bitcoin appreciation)
- Even if Bitcoin crashed 50%, still ahead of credit cards

**Option 2: Auto-Convert Everything**
- 100% to USD instantly, zero Bitcoin exposure
- Just lower fees + loyal customers
- Perfect for risk-averse operators

**Option 3: Hold 100% Bitcoin**
- Maximum business value creation
- For those who believe in Bitcoin's trajectory
- Can handle volatility

## 🧡 How to Use This

**Orange-pilling a brewery:**
1. Read the main guide first
2. Study the brewery analysis for specific numbers
3. Print the brewery two-pager on card stock
4. Use the conversation guide when you talk to them
5. Leave the two-pager if they're busy — QR code links to full analysis
6. Share "Why 0.15 Bitcoin Matters" if they ask about long-term value

**Orange-pilling a coffee shop:**
- Same process, use the coffee shop analysis and two-pager
- Lower transaction size = still meaningful savings ($0.31/tx)

**Orange-pilling a liquor store:**
- Same process, use the liquor store analysis and two-pager
- Higher transactions = bigger fee savings ($0.66/tx vs $0.31/tx for coffee)

**The pattern works for any Square merchant:**
- Higher average transactions = better economics
- Breweries ($30 avg) save $0.63 per Bitcoin transaction
- Liquor stores ($32 avg) save $0.66 per Bitcoin transaction
- Coffee shops ($10 avg) save $0.31 per Bitcoin transaction
